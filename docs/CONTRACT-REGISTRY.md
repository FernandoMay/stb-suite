## Change control

Any contract change must update this file in the same documentation change as:
- exact contract ID;
- network passphrase/network name;
- deployed WASM hash;
- deploy and initialize transaction hashes;
- admin/resolver/oracle configuration (public keys only);
- date and verification source.

Never publish secret seeds, private keys, mnemonic phrases, or wallet recovery material.
